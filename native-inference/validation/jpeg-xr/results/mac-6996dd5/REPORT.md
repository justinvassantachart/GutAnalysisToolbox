# Native Mac JPEG-XR overlay: validated evidence snapshot

**PASS within the codec/package scope below.** [Run 37371362801, job
111969570023](https://github.com/justinvassantachart/GutAnalysisToolbox/actions/runs/37371362801/job/111969570023)
tested source `6996dd50f5ea06ac1f5ecb38c245139cb1508292` on native macOS 15.7.9
ARM64, Java 21.0.12.1, Apple clang 17.0.0 and official SWIG 4.5.1.

## What passed

- All **13 official upstream golden fixtures** decoded exactly through direct
  JNI, the direct-byte-buffer API, and actual Bio-Formats **8.5.0 service/codec**
  paths. Input hashes, dimensions, byte counts,
  golden decoded MD5s and native/Bio-Formats SHA-256s matched. Both native and
  final-overlay TSVs are byte-identical to the checked-in Linux reference
- All **59 published JNI signatures** match generated declarations, and the
  legacy byte-vector operations pass. The published `jxrlib-all:0.2.4` Java
  bindings are unchanged. All **34 packaging/checker unit
  tests** passed in this same Mac job
- The **final resource-only JAR was last on the actual runtime classpath**. Its
  recorded resource URL identifies the tested dylib, with zero replacement Java
  classes. A fresh JVM decoded all 13 fixtures again with empty native search
  paths and no library-path environment overrides
- The native dylib is ARM64-only, with a macOS **11.0 build target**, dependencies
  only on macOS `libc++` and `libSystem`, and no custom rpath. The preserved
  absolute `LC_ID_DYLIB` is its identity, not a runtime dependency. This run tested
  macOS 15.7.9, not macOS 11
- The corresponding source includes the preferred SWIG inputs and pinned legacy
  vector typemap. Regeneration used **exactly SWIG 4.5.1** and produced identical
  generated bytes. Independent inspection checked every **25 distribution and
  165 source payload checksums**; the ZIPs contain 26 and 166 entries including
  their own checksum files. Source, native binary and notice hashes all matched

This remains an **optional experimental codec overlay**, not full microscopy
reader validation. Full CZI/LIF containers, series/metadata/ROI interpretation,
installed Fiji GUI/classloader/updater behavior, signing/quarantine, other macOS
versions, all JPEG-XR formats, malformed inputs, encoding and long-running
concurrency were not validated. Do not distribute the loose resource JAR without
its matching source and notices; the wrapper's GPL-2.0-or-later headers remain
preserved alongside Microsoft and SWIG notices.
